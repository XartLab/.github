# XartLab

我们做给 AI Agent 用的工具：让它改代码、做设计、写剧本之前，先把该看的东西看清楚，做完之后有东西可查。

## 项目

- [code-intel-pipeline](https://github.com/XartLab/code-intel-pipeline)：在本地分析代码仓，生成架构地图、热点和变更影响面，并给结构回归设卡。Rust 写的。
- [design-pipeline](https://github.com/XartLab/design-pipeline)：前端设计流程。先写 DESIGN.md 和 MOTION.md，再写代码，做完在浏览器里实测。带风格包和模板。
- [dream-harness](https://github.com/XartLab/dream-harness)：短剧创作的一组 skill，从创意、大纲、剧本一路到分镜和提示词。
